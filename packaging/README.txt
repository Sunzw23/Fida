Fida for Windows (64-bit, Release build)

1. Extract the complete ZIP to a folder.
2. Run Install-Fida.ps1 from that folder (right-click > Run with PowerShell).
3. The installer copies the game into %LOCALAPPDATA%\Programs\Fida, creates a
   Start Menu shortcut and launches it.

Microsoft .NET 8 Desktop Runtime is required. If it is missing, the installer
opens the official .NET download page.

The game files live in the payload folder; keep Install-Fida.ps1 next to it.
